O código SKU é um código cadastrado pelo cliente e utilizado para identificar cada produto no sistema. Diferente do código de barras que é um código fixo, o código SKU pode ser personalizado pelo cliente. Esse campo é de uso interno do sistema e serve para vínculos internos como em planilhas.

O Mercado Livre é um marketplace disponível para integração com o ERP da Olist. Essa conexão possibilita importar pedidos para o ERP para gerenciá-los, além de efetuar o controle de estoque da plataforma, entre outras funções que otimizam a rotina do cliente. Recursos disponíveis Confira o que você pode gerenciar diretamente pelo ERP da Olist nesta integração: Receber produtos ✓ Enviar produtos ✓ Enviar e atualizar estoque ✓ Enviar e atualizar preços ✓ Efetuar cotações de fretes ✓ Receber pedidos ✓ Sincronizar situações dos pedidos da plataforma para o ERP ✓ Enviar dados das NF-es ✓ Enviar ras

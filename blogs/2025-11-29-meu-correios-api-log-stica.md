O Meu Correios é um sistema para gerenciar postagens, pré-postagens e impressão de etiquetas para quem utiliza contratos com agências dos Correios. Configurando a integração Para começar, você precisa instalar a extensão Token API no seu ERP . Siga os passos: Acesse menu > início > Loja de extensões .

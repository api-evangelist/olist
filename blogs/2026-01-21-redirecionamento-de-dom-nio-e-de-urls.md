Neste artigo, explicamos como fazer o redirecionamento de URLs do seu site antigo para o novo ou realizar o redirecionamento de domínio para administrar diversos endereços em um único plano de hospedagem. Redirecionando links antigos Este processo é necessário quando o site já existe e é preciso direcionar as URLs antigas para as atuais do Ecommerce, ou quando uma página é desativada e sua marca precisa direcionar o acesso para uma página ativa. Caso utilize Google Analytics ou Google Tag Manager, você pode obter a lista das URLs pelo Google Search Console.
